# Reaptirement — Faux Départ (bêta)

La Mort prend sa retraite. Tu reprends le poste.

Jeu incrémental : fauche des âmes de Paris au Néant, remplis le Grimoire, affronte les boss et débloque les pouvoirs de personnages célèbres.

## Télécharger

👉 **[Dernière version (Windows, zip ~1,7 Go)](https://github.com/WheezyHD/reaptirement-beta/releases/latest)** : dans « Assets », clique sur `Reaptirement-Beta-…-win64.zip`.

1. Décompresse le zip (clic droit > Extraire tout).
2. Lance `Reaptirement Beta.exe` dans le dossier « Reaptirement Beta ».
   Si Windows affiche « Windows a protégé votre ordinateur » (le jeu n'est pas signé) : « Informations complémentaires » puis « Exécuter quand même ».
3. Choisis ton pseudo au premier lancement.

En jeu : **F9** pour écrire une remarque, **F11** pour le plein écran.

## Questionnaire et bugs

Le site de la bêta : **https://reaptirement-beta.pages.dev** (guide, questionnaire, signaler un bug).

Pendant que tu joues, le jeu note ta progression (temps, achats, Moissons, boss, pouvoirs, fluidité, erreurs) et l'envoie au site pour équilibrer le jeu. Rien d'autre n'est lu sur ton PC.
