# Reaptirement — Faux Départ (bêta)

La Mort prend sa retraite. Tu reprends le poste.

Jeu incrémental : fauche des âmes de Paris au Néant, remplis le Grimoire, affronte les boss et débloque les pouvoirs de personnages célèbres.

## Installer

👉 **[Dernière version (Windows, ~1,4 Go)](https://github.com/WheezyHD/reaptirement-beta/releases/latest)** : dans « Assets », clique sur `Reaptirement-Beta-Setup-….exe`.

1. Lance l'installateur : le jeu s'installe tout seul (sans droits administrateur) et ajoute un raccourci sur le bureau.
   Si Windows affiche « Windows a protégé votre ordinateur » (le jeu n'est pas signé) : « Informations complémentaires » puis « Exécuter quand même ».
2. Choisis ton pseudo au premier lancement.

**Le jeu se met ensuite à jour tout seul** : il télécharge les nouvelles versions en arrière-plan (quelques Mo) et les installe quand tu le fermes. Ta sauvegarde est conservée.

Tu avais le zip de la 0.9.0 ou de la 0.9.1 ? Installe la nouvelle version une fois, puis supprime l'ancien dossier : ta sauvegarde est conservée.

En jeu : **F9** pour écrire une remarque, **F11** pour le plein écran.

## Questionnaire, bugs et nouveautés

Le site de la bêta : **https://reaptirement-beta.pages.dev** (guide, nouveautés, questionnaire, signaler un bug).

Pendant que tu joues, le jeu note ta progression (temps, achats, Moissons, boss, pouvoirs, fluidité, erreurs) et l'envoie au site pour équilibrer le jeu. Rien d'autre n'est lu sur ton PC.
